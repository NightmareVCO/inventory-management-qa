# inventory-management-qa
Educational inventory system highlighting key principles and practices of Software Quality Assurance


# Technologies Used
- Frontend: Next.js, React, TypeScript, Chakra UI
- Backend: Spring Boot, Keycloak, Hibernate Envers
- Tests: Playwright, JUnit, Cucumber
- Observability: Grafana, Prometheus
